# Woo Manager App

اپلیکیشن فارسی و مینیمال مدیریت فروشگاه ووکامرس.

## وضعیت نسخه 0.1.0

- پوسته Flutter با Material 3، RTL و حالت روشن/تیره
- صفحه اتصال اولیه فروشگاه
- داشبورد و دسترسی سریع تاپین، چاپ و پیامک
- کلاینت API افزونه Woo Manager

## اجرا

```bash
flutter pub get
flutter run
```

هیچ توکن سرویس خارجی نباید داخل این مخزن ذخیره شود.
