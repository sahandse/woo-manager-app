# Woo Manager App

اپلیکیشن فارسی و مینیمال مدیریت فروشگاه ووکامرس.

## نسخه پایدار 1.2.1

- اتصال امن QR و کد یک‌بارمصرف با بازیابی خودکار نشست
- مدیریت کامل سفارش، یادداشت، وضعیت و بازپرداخت
- مدیریت محصول ساده و متغیر، مدل‌ها، قیمت، موجودی، دسته، ویژگی و برند
- مدیریت مشتری، کوپن، دیدگاه، رسانه، نوشته و برگه
- ثبت مرسوله تاپین، دریافت و چاپ PDF و ارسال پیامک رهگیری
- گزارش فروش، خروجی CSV/PDF، پشتیبان و مرکز سلامت
- رابط فارسی RTL با Material 3 و حالت روشن/تیره
- صفحه مستقل سفارش‌ها با فیلتر وضعیت، بازخوانی و خطاهای فارسی
- تم روشن پیش‌فرض، رنگ زمردی و نمایش اعداد فارسی در سفارش‌ها
- دارک‌مود واقعی و ماندگار با دکمه مستقیم در صفحه اصلی و تنظیمات
- سازگاری سفارش‌ها با HPOS، نمایش وضعیت تشخیصی و جستجوی سفارش

## اجرا

```bash
flutter pub get
flutter run
```

هیچ توکن سرویس خارجی نباید داخل این مخزن ذخیره شود.

## خروجی انتشار

Workflow با نام `Android Release` فایل APK را می‌سازد. برای AAB امضاشده مارکت، این Secretها باید در مخزن تنظیم شوند:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

شناسه برنامه: `ir.sahand.woomanager.woo_manager_app`
